# 마스킹 규칙

리포트를 저장하기 전에 이 규칙을 적용한다. 발췌 · 표 · 명령 출력 · 본문 모두 대상이다.

| 대상 | 규칙 | 예 |
|---|---|---|
| IP 주소 | 마지막 옥텟을 가린다. 값 자체를 쓰지 않아도 되면 `…` 로 줄인다 | `10.0.3.xxx`, `client E…` |
| 이메일 | 아이디를 가리고 도메인만 남기거나 전부 `[email]` 로 바꾼다 | `***@example.com` |
| 학생 식별자 | `STU-` 접두어만 남기고 나머지를 `…` 로 줄인다 | `STU-…` |
| 토큰 · 세션 · API 키 | 값을 전부 지우고 종류만 적는다 | `Bearer [token]` |
| 비밀번호 | 값을 전부 지우고 `[password]` 로 적는다. 연결 문자열 속 비밀번호도 같다 | `password=[password]` |

## 역할 별칭

- 서로 구분해야 하는 IP 는 값 대신 역할 별칭으로 바꾼다: 서버는 `API-1` · `API-2`, 교사 단말은 `교사단말A` · `교사단말B` 처럼 쓴다.
- 같은 IP 는 리포트 전체에서 같은 별칭을 쓴다. 구분이 필요 없는 IP 는 별칭 없이 `…` 로 줄인다.
- 별칭과 원래 값의 대응표를 파일로 남기지 않는다. 별칭의 뜻은 리포트 본문에 역할로만 설명한다.

## 확인

- 저장 후 `grep -nE` 로 IP · 이메일 · `STU-` 뒤 숫자 · `token` · `password` 가 남았는지 확인한다.
- 줄번호, 건수, 시각은 마스킹 때문에 바꾸지 않는다.
